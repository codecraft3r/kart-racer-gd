# Pattern Pack Lines

A collection of 60 seamless line-based geometric patterns by Kenney, supplied as both vector SVG and pre-rendered PNG tilesheets. Every tile is monochrome on transparency, designed to tile horizontally and vertically for backgrounds, fills, and decorative surfaces in games, apps, and print work.

## Stats

- Assets: 60 unique patterns (Thick + Thin variants)
- PNG files: 125 (per-pattern 256px + 512px, plus 4 tilesheets + preview)
- SVG files: 60 (vector source, infinitely scalable)
- XML files: 4 (tilesheet definitions)
- Total files in archive: 203
- License: CC0 1.0 (public domain, no attribution required)

## Visual style

Minimal monochrome line-art, with a clear division between **Thick** and **Thin** stroke weights. Each pattern is a single geometric motif (hatching, herringbone, basket weave, hexagons, chains, chevrons, dots, grids, brick, diamonds, etc.) constructed from clean white strokes on a transparent background, so the patterns take on the color of whatever they sit on. Preview is shown on a sky-blue panel, but the actual tiles carry no color. Flat, geometric, perfectly tileable.

## Best for

- Tileable game backgrounds (top-down maps, board games, casual/arcade titles)
- UI fills, panels, dividers, and section backgrounds
- Loading screens, splash art, and menu textures
- Print, paper, and digital stationery (notebooks, planners, worksheets)
- Decorative overlays in 2D apps and websites
- Seamless textures for prototypes where you need a quick patterned surface
