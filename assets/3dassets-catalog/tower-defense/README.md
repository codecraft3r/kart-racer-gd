# Tower Defense

Isometric low-poly tower defense kit — 230 individual PNG sprites (landscape tiles, three tower color variants, decorative props) plus four packed spritesheets, ready to drop into a 2D TD prototype or jam game.

## Stats

- **Asset count:** 230 (per Kenney)
- **Archive:** 249 entries — 235 PNG, 4 XML (spritesheet atlas), 1 License, 2 link files, plus 1 Preview and 1 Sample at the zip root
- **PNG layout:** `PNG/Details` (24), `PNG/Landscape` (40), `PNG/Towers (brown)` (55), `PNG/Towers (grey)` (55), `PNG/Towers (red)` (55)
- **Spritesheets:** `landscape_sheet` 2048×512, `towers_{brown,grey,red}_sheet` 1024×512 (each with matching XML atlas)
- **Individual asset size:** roughly 70×70 to 130×120 px (isometric, transparent PNG)

## Visual style

Clean isometric, low-poly, flat-shaded with crisp anti-aliased edges. A floating grass island hosts a winding tan path, chunky stone castle towers, pine trees, white rocks, purple crystals, a small water tile and sand-colored building blocks — all set against a vivid blue background. The look is bright, modular and family-friendly: easy to mix-and-match into a small TD scene without further art work.

- **Palette:** grass green, path tan, stone grey, rock white, water/sky blue, tower red, crystal purple, tree green, wood brown
- **Tags:** isometric, low-poly, flat-shaded, vector-style, clean-edges, vibrant, modular, tileset, sprite-sheet, game-ready, family-friendly

## Best for

Tower defense games, isometric strategy prototypes, mobile TD projects, game-jam builds, casual / family-friendly games, level mockups and tutorials.
