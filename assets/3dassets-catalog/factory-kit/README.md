# Factory Kit

A modular low-poly 3D factory kit with 140 assets — robotic arms, conveyor belts, catwalks, hoppers, pipes, crates, control panels, doors, cranes, traffic cones and more — in Kenney's signature clean, cartoon style. Ideal for tycoon, automation, top-down or isometric game scenes.

## Stats

- Asset count: 140
- 3D formats: OBJ, FBX, GLB (each with MTL)
- Textures: 512×512 PNG colormaps (incl. alternate `variation-a` palette)
- Preview: 918×515 PNG
- File layout: top-level `Models/`, `Previews/`, `Preview.png`, `Preview (Variation A).png`, `Sample.png`, `Overview.html`, `License.txt`

## Visual style

- Low-poly, stylized, flat-shaded 3D models
- Soft purple / lavender machinery with bright orange accents
- Dark navy checkered floor, white highlights, dark gray structural elements
- Cartoon, clean, modular — snaps together to build factory interiors
- Available in two color variations (default purple/orange + brighter pink/orange)

## Best for

- Factory / industrial level design for games
- Manufacturing, automation or tycoon games
- Top-down or isometric game scenes
- Educational games about industry or robotics
- Modular scene construction with conveyors, pipes, hoppers and robotic arms
