# Nature Kit

A bright, low-poly isometric nature kit by Kenney featuring layered terrain tiles, trees, palms, rocks, wooden bridges, tents, fences, and flowing water, all rendered in a clean faceted style with a warm teal-and-terracotta palette. Ships as isometric and side-view PNG sprites alongside 3D source models (OBJ, FBX, GLB, STL, DAE) ready for both 2D tile engines and modern 3D pipelines.

## Stats

- **Asset count:** 330 assets (per Kenney description)
- **Files in archive:** 3,626
- **Formats:** PNG (1,640), OBJ / MTL / STL / GLB / FBX / DAE (329 each)
- **Layout:** `Isometric/` (1,317 tiles & sprites), `Models/` (1,980 files, 3D sources), `Side/` (323 side-view tree & prop sprites)
- **Sample tile sizes:** 512x512 isometric terrain tiles; 39x154 / 56x136 side-view tree sprites

## Visual style

Low-poly, flat-shaded, stylized cartoon miniature — faceted geometry with chunky silhouettes and no texture detail beyond color blocks.

- **Palette:** teal grass `#4FC4A8`, terracotta path `#D67A4A`, sand `#E8D4B0`, stone `#DCE3E8`, water cyan `#7DD3E0`, deep navy backdrop `#1E2B37`
- **Tags:** low-poly, isometric, flat-shaded, stylized, cartoony, vibrant, miniature
- **Subcategory:** isometric-nature
- **Category:** tile-set

## Best for

- Isometric level design and tile-based world building
- Low-poly outdoor environments in casual / mobile games
- 2.5D strategy, tycoon, and city-builder scenes
- Nature, forest, and farm settings needing ready-made props and terrain
