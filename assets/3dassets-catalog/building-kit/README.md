# Building Kit

A modular low-poly 3D building kit with 80 stylized architectural pieces (walls, doors, windows, roof sections, stairs, vents, chimneys) shipped in FBX, GLB, and OBJ formats with a shared 512×512 colormap texture.

## Stats

- Assets: 80
- Zip files: 416 (86 PNG, 79 FBX, 79 GLB, 79 OBJ, 79 MTL, plus docs)
- Texture: 512×512 colormap (variation A included)
- Previews: 918×515
- Formats: FBX, GLB, OBJ (+ MTL)
- License: CC0

## Visual style

Low-poly isometric 3D with a clean, stylized, hand-painted look. Soft lavender-purple walls with white trim, dark gray slate roofs, and red-orange accent details (doors, stair rails). Flat-shaded geometry on a transparent dark backdrop, ready to drop into stylized scenes.

## Best for

City and town builders, level prototyping, modular architecture, mobile and casual 3D games, stylized scenes, and any project needing ready-to-use building blocks in a friendly low-poly aesthetic.
