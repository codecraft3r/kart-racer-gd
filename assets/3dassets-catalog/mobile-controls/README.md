# Mobile Controls

A comprehensive set of flat, minimalist mobile touch-control UI sprites for on-screen gamepads, action buttons, and HUD overlays. Designed in a modern dark theme with consistent circular and rounded-pill buttons, soft white icons, and matching highlight states for pressed/active feedback.

## Stats

- Assets: 900
- Zip contents: 1,482 files
  - PNG sprites: 948 (Sprites/ + Spritesheets/)
  - SVG vectors: 462 (Vector/)
  - Sprite metadata XML: 22
  - License + project links: 3
- Sprite size: ~64×64 px base unit
- Formats: PNG (raster), SVG (vector), XML (TexturePacker)

## Visual style

Flat, minimalist, modern mobile-game UI. Muted dark-slate fills on near-black translucent panels; soft off-white iconography. Rounded circular and pill-shaped buttons with consistent stroke weight and matching highlight sprites for pressed/active states. Color palette: deep navy (`#0f1218`), charcoal panel (`#1a1f2e`), button fill (`#2a3142`), mid gray (`#6b7280`), light icon (`#a0a8b8`), white (`#ffffff`).

## Best for

- Mobile game HUD and touch overlays
- Virtual joysticks and d-pads
- On-screen action buttons (jump, fire, aim, attack, ability)
- Settings, menu, pause, and microphone toggles
- 2D/3D mobile, tablet, and Steam Deck-style input UIs
