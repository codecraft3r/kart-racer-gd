# Brick Kit

A clean, low-poly 3D modular brick kit in classic LEGO-style. Bright primary-colored beveled bricks, plates, slopes, and round pieces, plus assembled examples like houses, trees, and walls, all presented in a friendly isometric aesthetic.

## Stats

- 290 assets (per Kenney)
- ZIP contents: 1499 files
  - 301 PNGs (textures + per-piece previews)
  - 296 each in FBX, GLB, OBJ/MTL formats
  - License, Overview, and URL launchers
- Texture: 512x512 indexed colormap shared across pieces
- Per-piece preview thumbnails: 64x64 PNG

## Visual style

- Isometric camera, soft studio lighting on a dark checkered backdrop
- Low-poly, beveled edges — toy-like, not photoreal
- Saturated primary palette: red, green, blue, yellow, neutral gray
- Modular, snap-together brick logic with round, slope, and plate variants

## Best for

- Modular level building and sandbox games
- Isometric city, castle, or house builders
- Educational apps and kids' games
- Rapid prototyping with LEGO-adjacent aesthetics
