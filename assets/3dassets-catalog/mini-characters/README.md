# Mini Characters

A pack of 25 chunky, low-poly 3D mini humanoids and accessory props (wheelchairs, canes, first-aid kit, defibrillator, glasses, masks), ready to drop into casual games and prototypes.

## Stats
- Assets: 25
- Files in archive: 148
- 3D formats: FBX, GLB, OBJ (+ MTL)
- Textures: 512×512 PNG colormaps
- Preview thumbnails: 64×64 PNG

## Visual style
Low-poly 3D with soft flat shading, chunky limbs, big head-to-body ratio, and a cartoon, kid-friendly look. The cast is intentionally diverse (skin tones, hair, outfits, abilities). Palette is bright primaries over a neutral gray ground — playful, modern, and reads cleanly in an isometric top-down view.

## Best for
- Casual mobile and web games needing a diverse character cast
- Game jams and prototypes where you want humans and props fast
- Accessibility-themed games (wheelchairs, canes, medical aids)
- Isometric top-down 3D worlds
