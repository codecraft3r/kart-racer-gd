# Space Shooter Remastered

A complete 2D top-down space shooter asset pack with 295 game assets — player ships, enemies, meteors, lasers, power-ups, UI, and parallax backgrounds — all in a clean flat-vector retro arcade style.

## Stats

- **Assets:** 295 (per official description)
- **Total files in archive:** 327
- **Format:** PNG (301) · TTF (2) · OGG (7) · XML (1) · SVG (1) · SWF (1) · TXT (1)
- **Sprite sheets:** XML + SVG + SWF included
- **Backgrounds:** black, blue, dark purple, purple (256×256)
- **Sprite size range:** ~9×54 to 222×39 px (ships ~90–150px wide)
- **Bonus content:** 2 fonts, 7 SFX, vector sheets

## Visual style

- **Category:** 2D sprites / top-down shooter
- **Subcategory:** space-shooter
- **Style tags:** flat, vector, retro, arcade, top-down, 2D, clean-lines, low-poly
- **Palette:** deep purple / navy space backdrop, white hulls, orange + cyan-blue ship accents, lime-green lasers, brown meteors, yellow UI highlights
- Ships are geometric and low-poly-inspired with crisp white hulls and bold accent colors. Lasers are bright neon green. Meteors come in multiple shapes and sizes. UI uses a chunky futuristic font (kenvector_future) for score and ship counters.
