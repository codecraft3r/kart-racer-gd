# Interface Sounds

A clean, modern pack of 100 short user-interface sound effects from Kenney, delivered in OGG Vorbis. Designed for buttons, menus, toggles, notifications and other micro-interactions in apps, games and web prototypes.

## Stats

- **Assets:** 100
- **Format:** OGG Vorbis
- **Archive contents:** 104 entries (100 audio + License.txt + Patreon.url + folder marker)
- **Folder layout:** single `Audio/` directory with numbered variants (e.g. `click_001.ogg`, `back_001.ogg`)

## Visual style

The preview uses Kenney's signature flat, minimal icon language: a white circular badge holding a simplified speaker, paired with a dark gray rounded-square cursor tile, on a bright mint-green background. The look reads as clean, modern and UI-focused — matching the lightweight, production-ready feel of the sounds themselves.

- Mint green background (~`#3DDC97`)
- Pure white, dark gray (`~#2C2E33`), light gray accents
- Flat shapes, soft shadows, no gradients or textures

## Best for

- Button clicks, toggles and switches
- Menu open/close, navigation and back cues
- Notification chimes, alerts and confirmations
- App, web and game UI micro-interactions
- Rapid prototyping of interactive interfaces
