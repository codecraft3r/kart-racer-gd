# Isometric Miniature Prototype

A modular isometric block and character kit for paper-diorama style scenes, rendered in a clean flat-shaded vector look.

## Stats

- 60 assets
- 662 files in zip (651 PNG, plus license, links, samples)
- Tile size: 256x512 PNGs, palette-indexed
- Folders: `Angle/`, `Isometric/`, `Characters/`
- Each tile in 4 cardinal directions (E, N, S, W)

## Visual style

Isometric 2:1 dimetric projection, flat vector shading with subtle face-by-face tone variation, modern and minimal. Warm orange/amber blocks sit on a soft cream floor grid for a "wooden toy" or "architectural model" feel. Includes 2 sample humanoid characters.

## Best for

- Isometric level prototyping and grayboxing
- Paper-diorama style game scenes
- Architecture and room-layout mockups
- Educational or onboarding visualizations
