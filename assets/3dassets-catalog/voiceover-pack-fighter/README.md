# Voiceover Pack (Fighter)

A drop-in pack of 45 short, high-energy announcer voice lines for fighting / brawler / arcade-style games. Filenames match the spoken phrase (e.g. `fight.ogg`, `round_1.ogg`, `you_win.ogg`, `flawless_victory.ogg`, `combo_breaker.ogg`, `sudden_death.ogg`), so you can wire them up to game events without renaming.

## Stats

- Assets: 45 voice clips (matches `og_description`)
- Format: Ogg Vorbis (`.ogg`)
- Total zip entries: 51 (47 audio + License + Preview + 2 URL bookmarks)
- Layout: single `Audio/` folder, `lowercase_underscore` filenames
- License: CC0 (public domain)

## Visual style

Cover art follows the Kenney brand language: a flat teal/mint-green background with a white circular badge holding a simplified grey loudspeaker icon, paired with a small dark rounded-square chat bubble showing a crossed-swords combat glyph. Clean, flat, friendly — instantly readable as "audio for a fighter game."

Palette: teal/mint green (`#4ECCA3`-ish), white, light grey, dark slate/charcoal.

## Best for

- Fighting / brawler / VS game announcer call-outs
- Round and match flow: `round_1`–`round_5`, `begin`, `fight`, `final_round`, `time`, `sudden_death`, `tie`, `tie_breaker`
- Results: `you_win`, `you_lose`, `winner`, `loser`, `flawless_victory`, `game_over`, `it's_a_tie`
- Combos and kills: `combo`, `combo_breaker`, `multi_kill`, `kill_him` / `kill_her` / `kill_it`
- Game-mode intros: `arcade_mode`, `story_mode`, `survival_mode`, `battle_mode`, `deathmatch`, `championship_mode`
- Player / setup prompts: `player_1`, `player_2`, `choose_your_character`, `prepare_yourself`, `ready`
- Fast prototype audio for any combat-flavored game jam or vertical slice
