# Tanks

A 2D tank-battle sprite pack in Kenney's signature flat-vector style. Multiple tank hulls in green, tan/sand, and gray, each swappable with several turret/cannon variants and muzzle flashes, plus rolling treads animation frames, six bullet/missile projectiles, a 12-frame explosion sequence, a wooden crate prop, arrow UI indicators, and a flying airstrike missile. Side-view composition that also reads well top-down, built for side-scrollers, defense games, and arcade combat.

## Visual style

Flat 2D vector, rounded shapes, no outlines, clean shading, slight 3/4 read on turrets. Bright saturated palette:

- Grass greens (#5BB04A, #7BC164, #A8DC8A)
- Sky blues (#B8D8E8, #8FB8D8)
- Sandy tan (#D9C49A, #A88858)
- Steel grays (#4A4A4A, #7A7A7A)
- Explosion reds/oranges/yellows (#E94B3C, #F4A93C, #F8D43A)
