# UI Audio

A small library of 50 short UI sound effects by Kenney — clicks, mouse clicks, mouse releases, rollovers, and a generous set of switch/toggle sounds — delivered as `.ogg` files. The preview art is a flat-vector speaker paired with a settings/toggles icon on a teal-green background, signaling the package's focus on interactive UI feedback.

## Stats

- **Assets:** 50 sound effects (per `og_description`)
- **Files in zip:** 56
- **Audio files:** 52 `.ogg` (50 in `Audio/`, plus `Preview.ogg` at top level)
- **Format:** OGG Vorbis
- **License file:** `License.txt` (CC0)

## Visual style

- Flat 2D vector preview, minimalist/iconographic
- Soft, friendly geometry: rounded square settings card, circular plate, soft speaker cone
- Limited 5-color palette: teal-green background, white, light gray, dark gray, black
- The visual language matches the audio — clean, neutral, "interface" — designed to drop into any modern game or app UI without feeling stylistically heavy

## Best for

- Button click and confirm feedback
- Mouse hover / rollover sounds
- Toggle, switch, and checkbox interactions
- Tab changes, panel open/close, and other discrete UI events
- Casual, mobile, and web games that need a tidy default UI sound kit
- Prototyping interactive apps and dashboards
