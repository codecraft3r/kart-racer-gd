# Sci-Fi RTS

A top-down 2D sci-fi real-time strategy sprite pack set on a rust-red alien or Mars-like terrain, with a flat cartoon vector look and subtle shading. The set is a complete RTS kit: domed command structures, hangars, factories, and defensive turrets (cool gray with red accents); red and blue military vehicles (tanks, rovers, walkers, transports); small infantry units; plus an environment layer of purple and green alien trees, gray rocks, and a winding ice-blue river.

## Stats

- 120 game-ready assets
- 259 PNG files in the archive
- 64x64 base tile size, RGBA with transparent backgrounds
- Ships in two resolutions: Default (1x) and Retina (2x)
- Bundled Spritesheet (PNG + XML) and Tilesheet (PNG + info.txt) for fast integration
- Editable Vector source included (SVG, plus a legacy SWF)
- License: CC0 1.0

## Visual style

- Top-down, slightly-elevated perspective, tile-based
- Flat cartoon vector look with light shading for depth
- Cool gray structures and chassis with red/orange accent details
- Two-tone faction palette: warm red vehicles vs. cool blue vehicles
- Alien-flora environment: purple and green trees on rust terrain
- Iconic icon-graphic readability at small sizes (good for HUD/unit portraits)
