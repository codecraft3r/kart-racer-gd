# Medals

A flat-style set of 24 ribbon-and-medallion achievement icons by Kenney, with each medal pairing a colored striped ribbon (red, blue, gold, green, purple) and a circular metallic disc in gold, silver, or bronze carrying simple rank, star, and symbol motifs. Includes matching transparent PNGs, a combined spritesheet, and an SVG source for easy reuse and recoloring.

## Stats

- Assets: 27
- Zip files: 38 (31 PNG, 1 SVG, 1 TXT, 2 URL, 3 directory entries)
- Top-level folders: `PNG/`, `Spritesheet/`, `Vector/`
- PNG sample size: 41x75 per medal sprite (palette-indexed, P mode)
- License: CC0 1.0

## Visual style

Flat vector with a subtle highlight for shine. Clean, readable at small sizes; ribbon-led composition with circular metallic medallion; ribbon and medal come in coordinated color pairs (gold, silver, bronze across red, blue, green, purple, and tricolor ribbons). Strongly reminiscent of classic arcade/quiz game rank badges.

## Best for

Game achievement systems, leaderboards, trophy cabinets, rank/grade indicators, event rewards, quiz or kids-app prizes, and any UI surface that needs a small celebratory badge icon.
