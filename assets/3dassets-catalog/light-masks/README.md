# Light Masks

A 152-design set of grayscale alpha light masks for 2D games, provided in three variants per design (Default, Inverted, Transparent). All masks are 512x512 PNGs covering spotlight cones, radial gradients, fan/propeller shapes, geometric window and arch cutouts, organic cellular noise, star fields and foliage silhouettes. Designed as drop-in alpha textures for lighting, shader masks and particle effects.

## Stats

- Asset count (per og_description): 150
- Unique mask designs: 152
- Variants per design: 3 (Default, Inverted, Transparent)
- Total PNG files: 457 (456 design variants + 1 root Preview.png)
- Format: PNG, 512x512
- Color modes: palette and RGBA
- ZIP files included: License.txt, Preview.png, two `.url` shortcuts, three variant folders

## Visual style

Pure grayscale alpha masks with strong contrast. The set blends hard-edged geometry (conical beams, square windows, arches, fan blades) with soft falloff gradients (radial circles, blurred cones) and organic noise (cellular, dotted star fields, foliage silhouettes). A clean, tile-friendly, modern 2D-game art style that works equally well for subtle ambience or hard-edged theatrical lighting.

Style tags: grayscale, alpha-mask, soft-gradient, high-contrast, minimal, 512x512, tile-friendly, noise-texture.

## Best for

- 2D game lighting and bloom effects
- Spotlight, torchlight and flashlight cones
- Window, doorway and arch light cutouts
- Atmospheric vignette overlays
- Particle alpha textures for sparks, smoke and dust
- Shader masks for screen-space lighting passes
