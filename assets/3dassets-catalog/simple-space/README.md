# Simple Space

Flat 2D top-down space game art with rounded cartoon ships, asteroids, satellites, stations, enemies, stars and radar HUD icons. Clean white silhouettes on dark circular dials, accented with yellow/orange flame and purple effect highlights against a bright sky-blue background. Ships (A–L), enemies (A–E), satellites, stations, meteors, stars and iconography ship as 64×64 PNGs in Default and @2x Retina sizes, plus a spritesheet, a tilesheet and a vector SVG.

## Visual style

- Flat 2D vector, minimal hard-edge shapes
- Cartoon / rounded silhouettes, white-on-dark aesthetic
- Top-down perspective for gameplay, side-on accent icons
- Accent palette: bright sky blue background, hot yellow-orange flames, purple effects
- Two 3×3 radar / scope dials demonstrate HUD composition (targeting, mission, map)
- Family-friendly, readable at small sizes — well suited for casual and mobile games

## Best for

- 2D top-down space shooters (twin-stick, shmup, vertical scroller)
- Arcade and mobile space games
- Tower defense or roguelike space themes
- Sci-fi mini-games, prototypes, game jams
- HUD / radar / scope UI prototyping
