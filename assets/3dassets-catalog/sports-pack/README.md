# Sports Pack · Kenney

A top-down 2D sports sprite pack from Kenney — rounded cartoon player characters, sports equipment props, and field tilesets (grass, mown grass, gravel, tarmac, ice, beige) ready to drop into arcade-style football, hockey, or generic field-sport games. Flat vector art with bright saturated colors and clean tile-based layouts.

## Visual style

- Top-down, orthographic camera-friendly sprites
- Flat vector art with simple soft shading
- Cartoon / chibi character silhouettes (round heads, stubby bodies)
- Bright saturated palette: field greens, white lines, red/blue/orange jerseys, brown skin tones
- Tile-based field surfaces (grass, mown, ice, tarmac, gravel, beige, transparent)
- Clean linework, minimal texture noise
