# Planets

A pack of 50 pre-rendered, painterly 2D planet sprites in Kenney's signature flat-cartoon style — soft-shaded, no outlines, with organic camo-style surface splotches. Includes finished planets plus building-block parts (lights, noise textures, base spheres) so you can compose your own worlds.

## Stats

- **Asset count:** 50 (per Kenney's official description)
- **Format:** PNG, palette-indexed (`P` mode)
- **Resolutions:** 1280×1280 (planets), 1024×1024 (parts), 918×515 (preview/sample)
- **Total files in zip:** 57 (54 PNG + License.txt + 2 .url shortcuts)
- **Subfolders:** `Planets/` (10 finished worlds), `Parts/` (43 building blocks: 11 lights, 28 noise textures, 3 base spheres)

## Visual style

Painterly flat-cartoon, soft 3D rounded shading, no outlines, organic blob-splotch surface patterns. Family-friendly sci-fi aesthetic with a vibrant palette: sky blue, earth blue/green/white, brick red, warm tan, and lavender/violet. Reads well at any scale from thumbnail up to full-screen background.
