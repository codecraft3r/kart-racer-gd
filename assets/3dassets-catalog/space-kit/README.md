# Space Kit

A vibrant isometric sci-fi game kit featuring a Mars colony — astronauts, habitats, rovers, rockets, mining rigs, satellite dishes, and rocky red terrain — all rendered in Kenney's signature low-poly, flat-shaded style. Ships in two parallel formats: 2D isometric PNG sprites (8 directions) and full 3D models (OBJ, FBX, GLB, DAE, STL).

## Visual style

Low-poly, flat-shaded isometric dioramas with soft bevels and a warm Mars palette. Every asset is given the same chunky, friendly silhouette and ships in 8 isometric directions so they tile cleanly in a 2.5D grid.

- **Perspective:** Isometric, 8 directions (N/NE/E/SE/S/SW/W/NW)
- **Shading:** Flat / cel-like, no PBR
- **Linework:** Clean silhouettes, subtle bevels, no outlines
- **Palette:**
  - `#d57a4d` rust orange (terrain)
  - `#b85a3a` deep rust (terrain shadow)
  - `#e8e8e8` off-white (habs, suits)
  - `#c5c5c5` light grey (metal)
  - `#f5b820` gold/yellow (accents, lights)
  - `#2a2a2a` near-black (trim, windows)
  - `#1a1f3a` deep navy (space background)
