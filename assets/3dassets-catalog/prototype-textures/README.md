# Prototype Textures

A pack of flat-color, grid-overlaid surface textures designed for **3D level prototyping and greybox/placeholder art**. Surfaces come in six bold color sets with a subtle white grid pattern, so blocks read as clearly as game-dev placeholder geometry rather than final art.

## Stats

- Asset count: 75
- Total files in zip: 117
- PNG textures: 80 (6 color sets × 13 textures, plus Preview/Sample)
- Vector assets: 13 SVG + 13 SWF
- PNG texture size: 1024×1024, palette-indexed (`P` mode)
- Color sets: Dark, Green, Light, Orange, Purple, Red

## Visual style

Bold, low-poly voxel aesthetic — stacked cube blocks viewed from a three-quarter perspective, with a subtle white grid overlay and tiny "WALL"/"FLOOR" block labels. Flat-color surfaces on a neutral dark background, with small bright accent cubes (green) that pop against the dominant red/purple/orange/gray palette. The look reads as deliberate prototype art: clean, geometric, and instantly readable as "not final art".

## Best for

- 3D level prototyping, blockouts and greyboxing
- Color-coded level design (one color per room, zone, or function)
- Game-jam and indie prototypes that need a consistent placeholder look
- Tutorial, mockup and didactic 3D scenes
- Architecture and layout walkthroughs
- Pairing with Kenney's voxel/prototype model packs for a unified dev style
