# Tappy Plane

A cheerful 2D side-scrolling tap-to-fly game art set in Kenney's signature flat cartoon style. The pack centers on a cute yellow biplane dodging brown mountain peaks while collecting gold stars, with everything needed to ship a Flappy Bird-style mobile casual game: hero planes in multiple colors and animation frames, full number/letter sets, UI buttons and medals, four ground variants, packed spritesheets with Starling XML metadata, and a master vector SVG.

## Stats

- **Assets:** 75 (per Kenney's package description)
- **Total files in archive:** 96
- **Formats:** 83 PNG (paletted, transparent), 1 SVG vector master, 2 Starling XML spritesheet descriptors, 2 .url links, 1 License.txt
- **PNG subfolders:** Planes (13), Letters (27), Numbers (11), UI (13), root (20 — backgrounds + 4 ground variants)
- **Spritesheets:** `Spritesheet/sheet.png` (1024×2048) and `Spritesheet/planes.png` (256×512)
- **Sample hero size:** plane sprites 88×73 px, background 800×480 px, score numbers ~53×78 px

## Visual style

- **Style:** flat, cartoon, mobile-casual, kid-friendly
- **Look:** chunky rounded silhouettes, bold solid colors, soft outlines, minimal shading
- **Mood:** bright, sunny, cheerful — daytime sky
- **Composition:** side-on 2D, designed for portrait/vertical tap gameplay
- **Origin:** vector-first (master `Vector/tappyPlane_vector.svg`), rasterized to paletted PNGs

## Best for

- Flappy Bird-style tap-to-fly games
- Mobile casual / endless runner games
- Side-scrolling 2D arcade games
- Game-jam prototypes and rapid vertical slices
- Family-friendly or kids-game projects
