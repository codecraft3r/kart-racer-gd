# Game Icons

A 105-icon UI/glyph pack of flat, rounded geometric icons covering navigation, media controls, settings, commerce, and gamepad button prompts. Delivered in both Black and White color variants at 1x and 2x, plus spritesheets and editable vector sources.

## Stats

- 105 icon assets
- 443 files in archive
  - 425 PNG icons (50x50 RGBA, 1x + 2x in Black and White)
  - 4 PNG spritesheets (1024x512 and 1024x2048, Black and White)
  - 4 XML spritesheet metadata files (TexturePacker)
  - 2 Adobe Illustrator vector sources
  - 2 SVG vector sources
  - 1 license.txt
- Preview image: 918x515 RGBA PNG

## Visual style

Flat, minimalist monochrome glyphs with rounded corners and chunky proportions. Each icon is a single solid color (white or black) with no shading or gradient, designed for legibility at small sizes. The preview is laid out as a clean grid on a flat mid-blue background.

- Style tags: flat, geometric, monochrome, rounded, minimalist, glyph, ui, two-color, clean
- Palette: white (#FFFFFF), black (#000000), mid-blue background (#3F8FCB)

## Best for

- Game HUD and menu icons
- Settings and configuration screens
- Controller button prompts (ABXY, L/R, L1/R2, Start/Select)
- Inventory and action buttons
- Mobile and casual game UI
- Tutorial and onboarding overlays
