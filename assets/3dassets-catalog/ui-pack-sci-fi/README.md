# UI Pack: Sci-Fi

A clean, futuristic game-UI kit on a bright blue backdrop: light-grey rounded panels with soft drop shadows and corner rivets, notched red header tabs, and a consistent four-color accent system (red, yellow, green, cyan) reused across buttons, status indicators, progress bars, energy cells and vertical meters. Ships as both pixel-perfect PNGs and scalable SVGs, plus a matching Kenney Future typeface for HUD text.

## Visual style

- Light grey panel base (`#DDE3E8`) on a mid-blue stage (`#4A8FCB`)
- Rounded corners, soft drop shadows, decorative rivets/screws
- Notched red header tabs to label each panel
- Four-color accent system: red `#E74C3C`, yellow `#F1C40F`, green `#2ECC71`, cyan `#1ABC9C`
- Status indicators as round dots and octagonal nodes with diamond cores
- Custom cursor (arrow + star/sparkle variant) in matching style
- Flat vector look with subtle gloss on progress bars; pairs with the Kenney Future typeface

## Best for

- Sci-fi and space game HUDs
- Ship status, reactor, energy and shield meters
- Control, settings and inventory panels
- Dialogue and yes/no prompts
- Main menu and pause screens
- Indie prototypes, mockups and game-jam builds
