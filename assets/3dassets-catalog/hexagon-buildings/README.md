## Visual style

- Isometric 3/4 perspective, hex grid
- Low-poly, flat-shaded, cartoon-clean outlines
- Palette: stone gray `#A8AEB4`, terracotta orange `#D85A2A`, grass green `#7AB957`, water blue `#B8E0EC`, wood brown `#8B5A3C`
- Delivered as both individual tile PNGs and a packed 1024² sprite sheet (with Starling XML) plus a vector SVG source

## Best for

- Tower defense and turn-based strategy games on a hex grid
- Lightweight city builders and settlement simulators
- Board-game / tabletop-style map illustrations
- Rapid prototyping of hex-based maps with thematic architecture
