# Impact Sounds

130 game-ready impact and footstep sound effects (Ogg Vorbis) covering a wide range of surfaces and object materials — designed for rapid prototyping in 2D and 3D games. Bundled by Kenney, CC0 licensed.

## Stats

- **Format:** OGG (`.ogg`) — 130 audio files
- **Total archive entries:** 134 (audio + license + project links)
- **Asset count:** 130
- **Category coverage:** footsteps (5 surfaces × 5 variants) + impacts across 21 material/weight buckets
- **Top-level layout:** `Audio/` (131 entries), `License.txt`, `Kenney.url`, `Patreon.url`

## Visual style

Kenney's signature flat-vector aesthetic. The cover art is a single white circular badge on a bright mint-green background, containing a stylized dark speaker icon and a smaller charcoal tile with a phone/impact glyph. Clean, geometric, minimalist — instantly recognizable as Kenney.

Palette: mint green, teal, white, light gray, charcoal, dark navy.

## Best for

- Footstep audio across carpet, concrete, grass, snow, and wood
- Object impact impacts: glass, metal, wood, plate, plank, bell, tin, generic
- Combat / punch hit reactions (light, medium, heavy)
- Mining / tool-on-material impacts
- Soft and generic UI feedback hits
- Drop-in SFX for game jams and prototypes
