# Top-Down Tanks

Top-down 2D game-art pack of cartoon tanks, bullets, smoke puffs and battlefield props. Tanks come in four body color schemes (blue, beige, green, dark) with optional silver turrets, plus matching `_outline` variants. Designed for fast top-down shooter prototypes and arcade-style games.

## Stats

- Asset count: 85 (per package description)
- Total files in zip: 101
- File types: 89 PNG, 1 SVG, 1 SWF, 1 XML, 1 TXT (+ 8 directory entries)
- Top-level layout: `PNG/`, `Spritesheet/`, `Vector/`, plus `preview.png`, `sample.png`, `license.txt`
- PNG subfolders: `Bullets` (24), `Environment` (5), `Obstacles` (11), `Smoke` (24), `Tanks` (22)
- Sample sizes: bullets ~12x26 px (20x34 with outline); tanks and obstacles ~50-80 px; preview/sample 918x515
- Includes a packed spritesheet (`Spritesheet/sheet_tanks.png` + `sheet_tanks.xml`) and vector sources (`Vector/vector_tanks.svg`)

## Visual style

- Top-down 2D sprite art, cartoon / slightly chibi proportions
- Flat solid fills, no gradients, clean readable silhouettes
- Bright saturated palette: blue, beige/tan, olive green, dark gray, silver, sand, grass green
- Terrain tiles in the sample: sand, hex-patterned dirt, grass
- Obstacles: trees, bushes, sandbag walls, crates, oil drums
- Retro arcade / mobile-game aesthetic, optimized to read clearly at small sizes

## Best for

- Top-down tank shooters
- Mobile and web (HTML5) arcade games
- Rapid prototyping and game jams
- 2D projects in GameMaker, Unity, Godot, Phaser, etc.
